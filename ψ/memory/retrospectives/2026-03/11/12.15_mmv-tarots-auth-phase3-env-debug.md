## Technical Details

### Files Modified
- `app/api/auth/liff-verify/route.ts`: Refactored to thin orchestrator.
- `lib/server/services/line-identity-service.ts`: (New) Domain logic for LINE verification.
- `lib/server/services/auth-session-service.ts`: (New) Manual session issuance for Better-Auth.
- `__tests__/services/line-identity-service.test.ts`: (New) 130 lines of coverage.
- `docs/auth-ownership-matrix.md`: Updated module definitions.

### Key Code Changes
- **Gateway Pattern**: การใช้ `verifyAndLoadLineIdentity` และ `issueSessionResponse` ทำให้ API Route เหลือเพียง 3 ขั้นตอนหลัก (Verify -> Resolve -> Issue) อ่านง่ายและบำรุงรักษาง่ายขึ้นมาก
- **Deterministic Error Mapping**: มีการใช้ `LineIdentityError` เพื่อแมปสถานะจาก LINE API (401, 403) กลับไปเป็น HTTP Response อย่างถูกต้อง

### Architecture Decisions
- **Service-Oriented Auth**: ตัดสินใจไม่ให้ API Route เรียก Better-Auth internals ตรงๆ เพื่อเตรียมความพร้อมให้ Phase 4 (Multi-Provider) ที่จะมาถึง

## What Went Well
- [Service Extraction]: การแยก Logic ออกไปทำให้อ่านง่ายขึ้นมาก -> ลดความเสี่ยงของการเกิด Bug เมื่อเพิ่ม Provider ใหม่ (Phase 4)

## What Could Improve
- [Context Switching]: การสลับไปมาทำให้การติดตามสถานะของ mmv-tarots ใน session นี้ดู "ขาดตอน" ไปบ้าง ในอนาคตถ้างาน HQ สำคัญมาก ควรปิด session เดิมให้เรียบร้อยก่อนสลับร่างครับ

## Blockers & Resolutions
- **Blocker**: LINE Error 400 (Invalid URL) บน Localhost
  **Resolution**: ยืนยันวิธีกำหนด Redirect URI และแนะนำให้เปลี่ยนไปเทสบน Production ที่มี HTTPS เพื่อตัดปัญหาเรื่อง Protocol Mismatch
