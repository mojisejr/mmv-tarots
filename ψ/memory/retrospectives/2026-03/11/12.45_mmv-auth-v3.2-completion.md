## ⚖️ Honest Feedback (Friction & Fixes)
- **Friction 1: Legacy Terminology**: มีคำว่า `lineIdentityEmail` ฝังอยู่หลายที่ ซึ่งภายใต้ Contract ใหม่ควรจะเป็น `providerIdentityEmail`. เราตัดสินใจทำการ Rename ทั้งระบบใน Phase 5 เพื่อลบ Technical Debt นี้ออกไป แม้จะขัดใจเรื่องประวัติ Git เล็กน้อยแต่คุ้มค่าในเชิงโครงสร้าง
- **Friction 2: Next.js Soft Routing Cache**: พบว่าการใช้ `router.push('/profile')` หลัง Login ในบางกรณีไม่ทำให้ Cookie ใหม่ถูกโหลดบน Client. เราจึงต้องยืนยันการใช้ `window.location.assign` ในส่วนของ Navigation Shell เพื่อบังคับ Re-read cookie จาก server
- **Friction 3: Test Isolation**: ในตอนแรกรัน Test แล้วติดปัญหาเรื่องการ Mock `Better-Auth` session. เราแก้โดยการแนะนำ `SessionShellContract` เพื่อให้ Test สามารถ Inject สถานะ User ได้โดยไม่ต้องรัน Auth engine จริงๆ
