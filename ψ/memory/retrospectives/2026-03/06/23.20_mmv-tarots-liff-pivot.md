### Key Architecture Decisions
- **LIFF-first Auth**: เปลี่ยนจาก Standard OAuth มาเป็น LIFF Access Token verification เพื่อลด Login friction ภายในแอป LINE
- **Messaging API Integration**: เชื่อมต่อ Official Account (OA) ผ่าน Messaging API ภายใต้ Provider เดียวกับ LINE Login เพื่อทำ Auto-Add Friend และ Push Notifications
- **Manual Payment Workflow**: ใช้ Static PromptPay QR + Slip submission แทน automated gateway เพื่อความรวดเร็วในการ Go-live

### Logic Alignment
- **Verification Strategy**: ใช้ระบบ Verify Access Token ฝั่ง Server (`/api/auth/liff-verify`) เพื่อเชื่อมต่อกับ `better-auth` session โดยใช้ `sub` (LINE User ID) เป็นตัวเชื่อม
- **Persistence**: รักษาข้อมูล User เดิมจาก Better-Auth/Prisma schema โดยใช้ LINE ID สื่อสารระหว่างระบบเก่าและใหม่
