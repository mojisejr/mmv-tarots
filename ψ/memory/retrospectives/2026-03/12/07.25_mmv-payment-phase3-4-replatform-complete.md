## Technical Details

### Files Modified
- `projects/mmv-tarots/components/features/payment/PaymentModal.tsx`: เปลี่ยนจาก Promise-based เดิมเป็น State Machine 4 จังหวะ (Creating, QR, Failed, Receipt).

- `projects/mmv-tarots/app/package/page.tsx`: เพิ่มระบบ Session Recovery ดึง Order ล่าสุดจาก `localStorage`.
- `projects/mmv-tarots/services/credit-service.ts`: ลบ Metadata ที่เกี่ยวข้องกับ Stripe/Omise ออกจนหมด.
- (Deleted) `lib/server/omise.ts`, `app/api/checkout/omise/*`, `app/api/checkout/stripe/*`, และ UI Components เลกาซี่อีก 13 ไฟล์.

### Key Code Changes
- **Payment Lifecycle**: ปรับการจัดการสถานะการจ่ายเงินมาอยู่ที่ Client-side State + Local Storage ทำให้ระบบทนต่อการ Refresh หน้าจอ (Resilient Payment).
- **QR Generation**: ใช้ `promptpay-qr` ฝั่ง Server และ Render ด้วย `qrcode` (Base64) ฝั่ง Client เพื่อความยืดหยุ่นและการแสดงผลที่รวดเร็ว.
- **Dependency Optimization**: ลบ `omise-node` และ `stripe` ออกจาก `package.json` ลด Bundle Size และ Security Risk.

### Architecture Decisions
- **Decision 1: Client-Side Persisted State**: เลือกเก็บ `orderId` ใน `localStorage` แทนการพึ่งพา Server Session อย่างเดียว เพื่อรองรับกรณีผู้ใช้ LIFF ปิดหน้าจอแล้วเปิดใหม่.
- **Decision 2: Hard Cleanup vs Soft Deprecate**: เลือก "Hard Cleanup" (Phase 4) ทันทีหลัง Phase 3 สำเร็จ เพื่อป้องกัน "Zombie Code" ที่อาจทำให้เกิดความสับสนในอนาคต โดยเฉพาะในจุดที่เป็น API Routes.
