### Key Code Changes

- **Test Coverage**: เพิ่ม Test Cases สำหรับ Protected Routes (`/profile`, `/history`) และตรวจสอบการส่งต่อ Query string แบบ 100% accuracy

### Architecture Decisions
- **Query Preservation Strategy**: ตัดสินใจใช้ Middleware เป็นตัวจัดการ Query state แทน Client-side เพื่อให้แน่ใจว่า First-touch attribution (Referral) จะไม่หลุดหายไประหว่างกระบวนการ Auth Redirect

## Blockers & Resolutions
- **Blocker**: `liff.state` loss during reload.
- **Resolution**: Replaced hardware-level reload with `next/navigation` router.replace and manual state parsing via Middleware.
