### Key Code Changes
- **Universal Gateway**: สร้าง Route `/liff` เพื่อจัดการ `liff.state` และแก้ปัญหา 404 เมื่อ User เข้าผ่าน Deep Link ตรงของ LINE.
- **Referral Wrap**: เปลี่ยนจากลิงก์เว็บตรงเป็น `https://liff.line.me/{id}/` เพื่อให้เปิดใน LINE Mini App เสมอ.
- **Parameter Forwarding**: แก้ไขให้ `liff.state` ส่งต่อ `ref` parameter เข้าสู่ URL ปลายทาง เพื่อให้ Middleware ดักจับคุกกี้ได้.

### Architecture Decisions
- **Gateway Pattern**: เลือกใช้หน้า Gateway เฉพาะแทนการดักจับที่ Root เพื่อลดความซับซ้อนของ `LiffProvider` และเพิ่มความ Deterministic ในการ Redirect.
- **Test-Driven Hardening**: ตัดสินใจเขียน Unit Test เฉพาะ Logic สำคัญ (URL Generation/Parsing) เพื่อให้แน่ใจว่าระบบ Referral จะไม่พังอีกเมื่อมีการอัปเดต Middleware.
