สุดท้าย การรัน Build และ Lint จนผ่าน 100% ก่อนจบงาน ช่วยให้ผมมั่นใจว่าการ Refactor ครั้งนี้ "Clean" และพร้อมสำหรับการพัฒนาต่อในคืนนี้ที่ Backend ของ Omise ครับ

## 🛠️ Friction Points & Failures
- **Build Constraints**: ในช่วงแรกเกือบจะมีปัญหากับ API Keys (Stripe) ที่หลงเหลืออยู่ แต่ได้ทำการใส่ Guard clause ไว้ในระดับ Build-time แล้ว ทำให้ไม่มี Error ขวางทาง
- **Context Management**: การทำ One-pass สำหรับ 4-5 ไฟล์พร้อมกันทำให้ต้องระวังเรื่องการทำ `replace_string_in_file` อย่างมาก เพื่อไม่ให้เกิดอาการ Patch ทับซ้อนหรือโค้ดพัง
