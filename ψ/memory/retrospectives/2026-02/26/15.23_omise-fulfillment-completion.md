## 📔 AI Diary (The Reflection)
I entered this session with a clear goal: bridge the gap between "payment creation" and "credit fulfillment". The initial technical debt was obvious—the reliance on webhooks for local development was a bottleneck. My first instinct was to just add the service call, but the "Oracle Standard" reminded me of the risks of duplicate transactions. 

I successfully implemented a robust try-catch block using Prisma's unique constraint error codes. This ensures that even if a webhook arrives milliseconds after a direct API response, only one set of stars is ever granted. One friction point was the discovery that Omise doesn't have a local CLI like Stripe; this necessitated a deeper research phase into alternatives like ngrok. 

Overall, the session was highly productive, moving the project from a "broken local state" to a "fully testable fulfillment flow" for credit cards.
