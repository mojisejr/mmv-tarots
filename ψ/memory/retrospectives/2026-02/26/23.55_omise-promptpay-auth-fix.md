## Technical Details

### Files Modified
- [`lib/server/omise.ts`](projects/mmv-tarots/lib/server/omise.ts): Updated SDK initialization to use both `publicKey` and `secretKey`.
- [`app/api/checkout/omise/route.ts`](projects/mmv-tarots/app/api/checkout/omise/route.ts): Added specific Omise error code metadata and QR image fallback from `charge.source`.
- [`components/features/payment/PromptPayQR.tsx`](projects/mmv-tarots/components/features/payment/PromptPayQR.tsx): Refactored `useEffect` to prevent timer dependency from resetting the polling cycle.
- [`__tests__/integration/omise-checkout-route.test.ts`](projects/mmv-tarots/__tests__/integration/omise-checkout-route.test.ts): Added tests for PromptPay success and QR fallback.

### Key Code Changes
- **Dual-Key SDK**: ย้ายการรับผิดชอบเรื่อง `publicKey` เข้ามาอยู่ใน Server Factory เพื่อรองรับ `.createSource()`
- **Polling Loop Recovery**: การแยก `remaining` (เคนานนับถอยหลัง) ออกจาก Dependency array ของ Hook การ Polling ทุก 4 วินาที เพื่อให้ loop ไม่โดนทำลายในทุกๆ วินาที
- **QR Metadata Fallback**: ระบบจะพยายามดึง `qrImageUrl` จากทั้ง Object `source` และ `charge.source` เพื่อรับมือกับ Race Condition ของ Omise API

### Architecture Decisions
- **Hybrid Source Management**: ตัดสินใจให้ Server ทำหน้าที่สร้าง Source แทนที่จะเป็น Client 100% เพื่อรักษาความปลอดภัยของ Transaction Metadata ที่ต้องส่งต่อให้ Charge ทันที
