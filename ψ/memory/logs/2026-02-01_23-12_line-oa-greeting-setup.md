# Snapshot: LINE OA Greeting Message Setup for mmv-tarots

**Time**: 2026-02-01 23:12
**Context**: การตั้งค่าด่านหน้า (First Touchpoint) สำหรับลูกค้าใน LINE Official Account ของโปรเจกต์ mmv-tarots

## Insight

การตั้งค่า Greeting Message สำเร็จตามแนวทาง **MimiVibe Persona** (นุ่มนวล, เป็นกันเอง, และเน้นผลลัพธ์):

### Greeting Structure
- **Balloon 1**: ต้อนรับด้วยชื่อเล่นลูกค้า (Nickname token) และเน้นย้ำ Vibe ของแบรนด์ (พื้นที่แห่งพลังบวก)
- **Balloon 2**: มอบลิงก์ Call to Action (CTA) เพื่อส่ง User เข้าสู่กระบวนการดูดวงทันที พร้อมช่องทางสอบถามปัญหาเบื้องต้น
- **Tone**: ใช้ภาษาที่เป็นกันเอง (ค่ะ/นะคะ) และ Emoji สายมูยุคใหม่ (✨/🌙/🔮) เพื่อสร้างความอุ่นใจ

### Next Steps to Sync
- [ ] นำ LINE ID (`@...`) ไปใส่ในเว็บ (Frontend Footer/Profile)
- [ ] เตรียม Rich Menu เพื่อรองรับคำถามต่อเนื่องหลังจาก User อ่าน Greeting จบ
- [ ] เตรียม Auto-response สำหรับ Keyword สำคัญ (เช่น "แจ้งปัญหา", "เติมเงิน")

## Apply When

- เมื่อมีการ Re-brand หรือเปลี่ยนลิงก์หลักของเว็บไซต์
