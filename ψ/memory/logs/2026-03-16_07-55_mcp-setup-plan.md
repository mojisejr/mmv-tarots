# Mission Blueprint: Next.js MCP Server Setup (#mmv-tarots-mcp)

ติดตั้งและกำหนดค่า Next.js MCP Server เพื่อเพิ่มความสามารถในการ Debug และ Runtime Inspection สำหรับ AI Agents

## Objective & Scope
- ติดตั้ง `.mcp.json` ในโปรเจกต์ [mmv-tarots](projects/mmv-tarots)
- เพิ่ม `next-devtools-mcp` เข้าไปในระบบ
- ยืนยันว่า AI สามารถเข้าถึง Runtime context ได้ (Errors, Routes, Logs)

## Phases of Execution

### Phase 1: Grounding & Verification
- [ ] ตรวจสอบความพร้อมของสภาพแวดล้อม (Next.js 16+ ✅)
- [ ] ตรวจสอบว่าโปรเจกต์ `mmv-tarots` รัน `npm run dev` ได้ปกติ
- **Exit Criteria**: มั่นใจว่าโปรเจกต์พร้อมสำหรับการเพิ่ม MCP Server

### Phase 2: Configuration
- [ ] สร้างไฟล์ `.mcp.json` ที่ Root ของ `projects/mmv-tarots`
- [ ] เพิ่ม Config สำหรับ `next-devtools-mcp`
- **Exit Criteria**: ไฟล์ `.mcp.json` ถูกสร้างและมีเนื้อหาถูกต้อง

### Phase 3: Testing & Handover (No Commit/Push)
- [ ] ทดสอบสั่งงานผ่าน AI (เช่น ถามเรื่อง Errors หรือ Routes)
- [ ] ทำการ Recap ผลลัพธ์ผ่าน `/sss`
- **Exit Criteria**: AI สามารถใช้งานเครื่องมือจาก MCP ได้จริง

## Critical Test Cases per Phase
- **Phase 2**: ตรวจสอบการมีอยู่ของไฟล์ `.mcp.json` ด้วย `ls -a`
- **Phase 3**: รัน `npx next-devtools-mcp@latest` (ถ้าทำได้ใน Terminal) หรือให้ User ทดสอบถามคำถามเชิงเทคนิคเกี่ยวกับ Runtime

## Risks & Rollback
- **Risk**: `npx` อาจจะช้าหรือติดเรื่อง Network
- **Rollback**: ลบไฟล์ `.mcp.json` ออก

## Verification Strategy
- **Build**: ไม่ได้รับผลกระทบเนื่องจากเป็นไฟล์ Config สำหรับ Tooling
- **Lint**: ไม่ได้รับผลกระทบ
- **Manual**: ทดสอบถาม AI @copilot "What are the current application errors?"
